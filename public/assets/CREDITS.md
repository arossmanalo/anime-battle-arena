# Asset Credits

Every third-party file in `public/assets/` goes here. See [docs/ART_SPEC.md](../../docs/ART_SPEC.md) for what's allowed.

All sound effects are synthesized in code; no third-party audio is used yet.

## fighters/gojo/ (sheet.png, portrait.png)

Built with the [Universal LPC Spritesheet Character Generator](https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/) and converted with `npm run import-lpc`. The files contain only the frames this game uses, rearranged, plus a cropped and enlarged portrait.

Several layers are also available under OGA-BY 3.0 / GPL 3.0. Licence details for every generator layer: <https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator/blob/master/CREDITS.csv>
